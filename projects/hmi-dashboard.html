TCMS Onboard HMI Dashboard

HTML CSS JavaScript SVG
Live demo Source code
What it is

A fully simulated train management dashboard with real-time speed gauge, route tracking, alarm system, and vehicle diagnostics — built as a single-page HTML application. The dashboard simulates a regional train running the Napoli Centrale–Salerno route, with autonomous acceleration, braking, and station-stop cycles.

Why I built it

I wanted to demonstrate that a functional HMI prototype can be built rapidly with web technologies, without heavy frameworks — useful for rapid prototyping and stakeholder demos before committing to platform-specific toolchains. In the railway industry, showing a working concept early saves months of back-and-forth on requirements.

How it works

The dashboard renders a complete TCMS interface: a vehicle synoptic with per-car status, a speed gauge with SVG arc rendering, traction and brake effort bars, a route progress map with station markers, a real-time alarm feed, door status monitoring, and environmental/power readings. The entire simulation runs in a 500ms interval loop, with realistic physics for acceleration, cruising, and braking phases. No external libraries — just vanilla HTML, CSS, and JavaScript.
